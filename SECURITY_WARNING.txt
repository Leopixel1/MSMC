⚠️ SECURITY WARNING ⚠️
=======================

IMPORTANT: READ BEFORE USING THIS SOFTWARE

This repository contains a Minecraft account checking tool that handles sensitive 
user credentials. Before using this software, you MUST understand the following:

🔴 CRITICAL SECURITY RISKS:
---------------------------
1. CREDENTIALS STORED IN PLAINTEXT
   - All checked accounts are saved without encryption
   - Anyone with access to your computer can read these files
   - Files location: results/[filename]/*.txt

2. EXTERNAL DATA TRANSMISSION
   - Account credentials are sent to external services
   - Discord webhooks receive your account information
   - Third-party APIs receive your email and password
   - Proxies can intercept all traffic

3. VULNERABLE DEPENDENCIES
   - urllib3 v2.2.2 has known security vulnerabilities
   - Requires update to urllib3 >= 2.6.0
